# ProyectoABD

## Descripción General

**ProyectoABD** es un proyecto académico desarrollado para el curso de **Aplicaciones de Bases de Datos** de la **Universidad Hispanoamericana**.

El objetivo principal del proyecto es diseñar e implementar una base de datos relacional para la administración integral de inventarios, productos, proveedores, empleados, órdenes de compra y bodegas, utilizando **Oracle Database 19c** como sistema gestor de bases de datos.


---

## Tecnologías Utilizadas

- Oracle Database 19c
- Oracle SQL Developer
- SQL
- Git
- GitHub

---

## Estructura del Repositorio

- **ProyectoABD.sql**  
  Script principal para la creación de la base de datos.

- **ProyectoABD_ER.pdf**  
  Diagrama Entidad-Relación (ERD) del proyecto.

- **Schema_original.pdf**  
  Esquema de referencia utilizado durante el proceso de diseño.

- **Documentación**  
  Archivos complementarios y documentación técnica relacionada con el proyecto.

---


## Requisitos Previos

Antes de ejecutar el proyecto, asegúrese de contar con:

- Oracle Database 19c o una versión compatible.
- Oracle SQL Developer.
- Permisos para crear tablas, restricciones y demás objetos dentro del esquema de trabajo.

---

## Instalación y Ejecución

### 1. Crear una conexión

Abra Oracle SQL Developer y establezca una conexión con la instancia de Oracle correspondiente.

### 2. Ejecutar el script principal

```sql
ProyectoABD.sql
```

### 3. Verificar la creación de objetos

Compruebe que se hayan creado correctamente:

- Tablas
- Restricciones
- Claves primarias
- Claves foráneas
- Relaciones entre entidades

### 4. Cargar datos de prueba

- Ejecute las consultas de creacion de datos
